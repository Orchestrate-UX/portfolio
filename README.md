# Portfolio

Static UX / Product Designer portfolio built with semantic HTML5, CSS3 and vanilla JavaScript. No build step; deploys directly on GitHub Pages (all URLs are relative).

- `index.html` – about / resume / contact
- `portfolio.html` – project overview with filters
- `case-study.html` – reusable case-study template (copy per project; sections: Overview, Challenge, Context, Research, Design process, Solution, Outcomes, Reflection)
- `assets/css/styles.css` – design tokens, components, layout
- `assets/js/main.js` – nav, reveal-on-scroll, filters, table-of-contents spy (honours `prefers-reduced-motion`)
- `assets/img/` – placeholder SVGs

Preview locally with `python3 -m http.server`.
